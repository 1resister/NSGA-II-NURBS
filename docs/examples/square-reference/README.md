# 正方形参考解：图片与数据来源

本目录保存原开发项目 `output/solution_001/` 于 2026-08-27 导出的少量结果摘要。对应 PNG 原图位于 [`../../images/square-example/`](../../images/square-example/)。这些文件用于解释输出，并非 2026-10-06 重新运行完整 NSGA-II 后的结果。

## 输入和决策变量

- 输入对应仓库 [`5stars.csv`](../../../SR5NURBS/SR5NURBS/5stars.csv)：9 个点，X 恒为 0，YZ 平面上边长 20 mm 的闭合正方形。
- 几何控制点数 24，速度倍率节点数 9，总决策槽数 34。
- 几何权重均为 1，速度倍率均为 1，端点跃度利用率为 0。
- 轮廓误差上限 0.15 mm；采样周期 0.002 s；全局时间光顺被接受。
- Snap 仍计算并绘图，但该例没有启用 Snap 硬约束。
- 共振诊断已启用；响应 RMS 上限为 Inf，因而没有有限响应上限约束。

## 摘要文件

| 文件 | 用途 |
|---|---|
| `constraint_status.csv` | 原始目标、误差和动力学约束、时间缩放和光顺状态 |
| `selected_solution.csv` | 解编号及完整决策变量 |
| `exported_solution_objectives.csv` | 候选目标和导出重评价目标的一致性 |
| `vibration_metrics.csv` | XYZ 跃度 RMS、Snap、Crackle 和共振指标 |
| `lmsc_points.csv` | 局部限速点及其弧长位置 |
| `pareto_candidates.csv` | 同批候选表；20 个候选的原始三个目标重合 |

原始数据记录总时长约 79.251657 s、双向轮廓误差约 0.080970357 mm、振动目标约 0.231564572。整体时间缩放因子约 103.160017，是此参考解的约束处理结果，不代表算法在其他路径上的加工效率。

图片按原文件直接复制，没有裁剪、重绘或人为削峰。图的坐标单位按项目配置读取：长度为 mm，时间为 s，速度/加速度/跃度/Snap 分别为 mm/s、mm/s²、mm/s³、mm/s⁴。图中的数值应结合 CSV 和各约束启用状态解释。

`pareto_front_selected.png` 沿用原绘图函数的“optimized endpoint jerk”标题和图例；此例利用率为 0，共享端点跃度功能未启用。该文字不表示本例启用了端点跃度优化。由于候选原始目标重合，图中大部分标记被选中解遮盖。

本目录未保存完整时序 CSV、最终种群检查点或随机种子。重新执行优化可生成新的候选和图片，但不保证得到与本目录完全相同的目标数值。若要了解同一参考决策的评价方法，请参阅仓库主 README 的“先评价一条参考轨迹”说明。
